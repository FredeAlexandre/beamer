## Decisions the operator should know

1. **"One encode"** is read as one encoded size and quality for the whole cluster (no per-sink sizes); with
   several PCs the design keeps one VT session per PC (independent recovery). If a single shared encoder was
   meant, §4.11 changes (PHASE2 §11 point 4).
2. **The kill switch leaves the route as it is** (it still names the Mac); every page shows "Turned off on
   <Mac>". This replaces the earlier default "turns the route off cluster-wide".
3. **Choosing the Mac's camera on the Mac's own page counts as the Mac action** that may show the macOS prompt;
   a selection from the PC never does.
4. **`sr` became a flow-level `time_map`** on the control channel (not a per-stream packet); audio streams carry
   it only to `video1` peers.
5. **DLL updates may require a Windows restart** until CW5's measurement says otherwise; the page says so from
   the running DLL's version.
